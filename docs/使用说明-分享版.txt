多AI聊天平台 · Windows 64 位分享版

完整解压到新文件夹，双击「多AI聊天平台.exe」。
请将 EXE 和 ai-roundtable 文件夹放在一起，不要仅复制 EXE。

首次运行不包含任何成员、API Key 或讨论记录。
在网页里添加成员，点击「获取API」，填写你自己申请的 API Key。
调用模型时需要联网，费用由你填写的 API Key 对应账号承担。

不同目录的程序使用独立后台；端口被占用时自动选择空闲端口。
关闭最后一个平台网页后，后台约 10 秒自动退出。刷新页面或还有其他平台标签页时不会退出。
未完成讨论会保存为已停止；再次启动后可查看记录。

原创代码采用 MIT 许可证；第三方依赖和素材的说明见 THIRD_PARTY_NOTICES.md。
